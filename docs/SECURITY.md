# 安全与合规基线

## 1. 安全目标

- 运营后台不能被未授权访问。
- 一个野人音乐客户端不能读取或修改另一个客户端的数据。
- Token、Provider 密钥和完整上游敏感 payload 不进入日志或错误响应。
- 中央服务不接收完整音频、NAS 绝对路径或野人音乐数据库。
- Provider 使用、缓存和再分发必须符合授权与服务条款。

## 2. 威胁模型

- 公网暴力登录、Token 泄露、伪造客户端和跨客户端越权。
- 大量曲目提交造成资源耗尽或 Provider 额度耗尽。
- 恶意标题、文件名、指纹或 Provider 响应触发注入、XSS 或超大解析。
- 非官方 Provider 变化、封禁、版权和缓存限制。
- 数据库、备份或日志泄露用户曲目偏好。

## 3. 运营管理员

- 密码使用 Argon2id，首次管理员初始化保持原子性。
- Session Token 为高熵随机值，服务端保存摘要和撤销状态。
- Cookie 设置 HttpOnly、Secure、SameSite 和明确 Path。
- 所有 Cookie 状态变更验证 CSRF Token 与 Origin。
- CORS 只接受 `WILDMAN_ALLOWED_ORIGINS` 的完整来源，不允许携带凭证的通配符。

## 4. 客户端凭证

- Token 使用 `wm_live_<prefix>_<secret>` 格式；`prefix` 为 64 bit 随机公开标识，`secret` 为 256 bit 随机秘密，两段均使用无填充 Base64URL。
- 完整 Token 只展示一次，数据库只保存完整 Token 的 SHA-256 摘要（无填充 Base64URL）和非敏感 `prefix` 段。
- 每个安装独立 Token；撤销、轮换和最后使用时间可见。
- Bearer 中间件从 Token 建立 `client_id`，请求体不得声明或覆盖客户端身份。
- Bearer 头严格拒绝重复请求头、Token 内空白和格式错误；错误与日志不包含 Token 原文或摘要。
- 限流、配额和幂等范围均绑定认证后的客户端。单节点 MVP 使用每客户端每分钟 120 次的进程内固定窗口，超限请求不会进入业务处理。
- 新安装为 `active`；撤销必须原子写入 `revoked` 和 UTC 撤销时间，且不能恢复。认证同时要求 `active` 且无撤销时间。
- 成功认证记录 UTC `last_seen_at`，同一客户端最多每 5 分钟写库一次。
- 客户账户 Session、设备码和用户码同样只保存摘要；账户身份不能访问运营 API。设备码 10 分钟过期且完整客户端 Token 只领取一次。
- 服务只保存订阅控制状态和用量，不接收或保存银行卡与支付凭证。

## 5. 数据隔离与输入

- 所有客户端 Repository 方法必须显式接收 `client_id`。
- 不存在或不属于当前客户端的资源统一返回 404，避免枚举。
- JSON 拒绝未知字段并限制请求体、字段、数组和指纹长度。
- `fileName` 只允许基名；拒绝绝对路径、分隔符和 `..`。
- 文本以纯文本展示，禁止未经净化使用 HTML。
- 不接受文件上传或客户端提供的任意 URL。

## 6. Provider 边界

- 只访问配置白名单中的 HTTPS 主机，限制重定向协议、主机和次数。
- 设置连接、响应头、总体超时和响应体上限。
- 对 401、403、429、5xx、超时和结构变化分类处理。
- 相同查询合并并发请求，缓存与负缓存防止请求风暴。
- 不绕过验证码、会员、登录、地区、付费或 DRM 限制。
- 每个 Provider 单独记录认证、限流、TTL、可缓存字段和再分发权限。

## 7. 隐私与日志

禁止记录密码、Cookie、Bearer Token、Provider 密钥、NAS 路径和完整敏感 payload。建议记录 Request ID、客户端内部 ID、解析请求 ID、Provider、耗时和错误类别。

曲目观测可反映用户收藏偏好，按隐私数据保护。必须提供保留期限、客户端删除和备份清理策略。音频指纹只用于识别，不作为音频内容再分发。

当前保留期为：已结束解析数据与孤立观测 180 天、过期来源观测额外宽限 30 天、最小运营审计 365 天。保留清理需管理员 Session 与 CSRF，并记录 `retention.purged` 审计；审计不包含操作详情正文。

## 8. 合规

- 优先使用允许批量导入和再分发的开放数据，例如按其许可使用 MusicBrainz 数据。
- “公开可访问”不代表允许批量抓取、永久缓存或商业再分发。
- 歌词和封面具有更高版权风险，MVP 默认不缓存。
- 非官方 Provider 在启用前必须完成风险说明和停用开关。

## 9. 运行与供应链

- 生产环境通过反向代理提供 HTTPS，容器以非 root 用户运行。
- 只持久化 `/data`，不挂载用户音乐目录。
- 数据库备份视为敏感数据并进行访问控制与恢复校验。
- Go 和 Bun 依赖使用锁文件；发布前执行漏洞、许可证、秘密和镜像扫描。
